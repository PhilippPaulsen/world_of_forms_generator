# Task 161: Bericht Null-Kanten ("Klick ohne Ziel"), kein Fix

Status: nur Bericht. Kein Code geändert (`sketch.js` und `core/` unberührt). Fundstellen auf Generator `main` `03b33d56` (identisch zu `8bb1bbb3` in `sketch.js`).

## Befund
Ein Klick auf denselben Knoten wie der erste Klick einer Verbindung erzeugt eine Verbindung `[a, a]` (Null-Kante).

- **Fundstelle:** `sketch.js:5370-5373`, `pressAt()`:
  ```js
  if (foundId !== null) {
      const conns = activeConnections();
      if (!conns.length || conns[conns.length - 1].length === 2) conns.push([foundId]);
      else conns[conns.length - 1].push(foundId);
  ```
  Eine offene Verbindung (`[a]`, ein Klick) wird mit dem nächsten Treffer geschlossen, **ohne zu prüfen, ob `foundId === a`**. Zwei Klicks auf denselben Knoten (oder zwei Klicks, deren Treffer-Radius denselben Knoten liefert: Maus 18 Einheiten, Touch max(18, 22 px), `nodeHit`, `sketch.js:5413`) ergeben `[a, a]`.
- **Gegenstück mit Prüfung:** `addRandomConnection()` (`sketch.js:5466`): `if (i === j) return;`. Nur der Klickpfad hat sie nicht.
- **Wirkung:** `[a, a]` liegt in `connections`, zählt als Linie (Zähler, Undo/Redo), erscheint als Kante im Export (`geometry.edges`, `adjacency` doppelt), und im Session-JSON (`_vConnections`, `core/session.js:232`, verlangt nur ein oder zwei positive Ganzzahlen, lässt gleiche Ids zu). Die Flächen ändern sich nicht (gemessen an zehn Exporten in Task 159: Roundtrip ohne die Null-Kanten bleibt flächengleich). Gezeichnet wird nichts (Länge 0).
- **Wie häufig:** in den zehn Kandidaten der A2-Presets steht sie in acht (`[14,14]` in allen acht, `[1,1]` zusätzlich in zwei).
- Eine halb fertige Verbindung `[a]` (ein einziger Klick, danach nichts mehr) bleibt ebenfalls in `connections` und im Session-JSON stehen; das ist absichtlich zugelassen (Länge 1) und kein Teil dieses Befunds.

## Vorgeschlagene Änderung (nicht ausgeführt, eine Zeile)
In `sketch.js`, zwischen `const conns = activeConnections();` und der `if`-Zeile (also vor Zeile 5372):
```js
if (conns.length && conns[conns.length - 1].length === 1 && conns[conns.length - 1][0] === foundId) return;   // a second click on the same node closes nothing
```
- **Verhalten danach:** der zweite Klick auf denselben Knoten wird ignoriert, die Verbindung bleibt offen (wartet weiter auf den Zielknoten). Das ist die einfachste Lesart. Alternative (nicht empfohlen): die offene Verbindung verwerfen (`conns.pop()`); das wäre eine neue, unsichtbare Bedienung.
- **Freie Endpunkte:** ein neuer freier Knoten (Zeilen 5362-5368) hat immer eine neue Id, kann also nie dem offenen Knoten gleichen; die Prüfung stört sie nicht.
- **Block-Kommentar-Regel:** die Zeile steht in `pressAt()`, nicht in `setup()`/`draw()`; ein `//`-Kommentar ist erlaubt (kein `/* */`, siehe `Claude.md`, Quelltext-Tests).
- **Cache-Marker:** `sketch.js` wird geändert, also `?v=` in `index.html`, `gallery.html`, `color-harmony/ui/index.html` anheben (Buchstaben, wie bisher), danach ein Studio-Sync.
