# SuisseIntl - font licence (PLACEHOLDER)

**This folder contains no font files.** Suisse Int'l is a commercially licensed typeface. The
licence allows web and print use but NOT redistribution in public repositories, so the web fonts
are no longer part of this repository. They are served only from
`https://bachmann-paulsen.de/fonts/` (CORS restricted to that website's domain). Locally and in
forks the stack falls back to Arial (metrics-matched) and the system font.
`.gitignore` and `tools/ui/test-no-suisse-fonts.js` keep font files out of the repository.

The licence is NOT covered by the MIT License of this repository (see `/LICENSE`). The proof of
the licence is held by the licensee, not by this repository.
